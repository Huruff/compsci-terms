Rekomendasi tempat belajar Cybersecurity
Kalau teman Anda ingin belajar cybersecurity dari nol, saya sarankan jangan langsung membeli kursus mahal atau langsung belajar hacking tingkat lanjut.

Cybersecurity memiliki beberapa jalur karier. Tempat belajarnya sebaiknya dipilih berdasarkan tujuan: ingin menjadi ethical hacker, security analyst, digital forensics specialist, atau security engineer.

Ada satu hal penting: belajar cybersecurity bukan hanya belajar cara meretas, tetapi juga memahami cara sistem bekerja, menemukan celah, mencegah serangan, dan menangani insiden.

Apakah harus bisa coding terlebih dahulu?

Tidak harus. Namun, Python, Bash, dan SQL akan sangat membantu ketika masuk ke tahap lanjutan.
Persyaratan berdasarkan platform
- Cisco: bisa dimulai tanpa pengalaman cybersecurity.
- TryHackMe: pemula dapat memulai dari jalur pengenalan.
- Hack The Box: sebaiknya sudah memahami Linux dan networking.
- PortSwigger: sebaiknya memahami HTML, HTTP, dan JavaScript dasar.
- OverTheWire: membutuhkan kesediaan menggunakan terminal.
- Google Certificate: dirancang untuk pemula, tidak mewajibkan pengalaman sebelumnya.

4. Jalur belajar yang saya rekomendasikan
Kalau teman Anda benar-benar mulai dari nol, saya menyarankan urutan berikut.
Roadmap belajar Cybersecurity
1. Tahap 1 — Computer & Networking Fundamentals
   Gratis
   Belajar:
   - IP address, DNS, TCP/IP, port
   - HTTP dan HTTPS
   - Client-server architecture
   - Dasar Linux dan Windows
   Platform: Cisco Networking Academy.
   
   Estimasi: 2–3 minggu
2. Tahap 2 — Linux & Security Fundamentals
   Gratis
   Belajar:
   - Linux command line
   - File permission
   - User dan privilege
   - Encryption dan authentication
   - Jenis serangan siber
   Platform: OverTheWire dan TryHackMe.
   
   Estimasi: 2–3 minggu
3. Tahap 3 — Hands-on Cybersecurity
   Bisa gratis
   Belajar:
   - Vulnerability scanning
   - SQL Injection
   - XSS
   - Password security
   - Network analysis
   Platform: TryHackMe dan PortSwigger.
   
   Estimasi: 3–5 minggu
4. Tahap 4 — Pilih spesialisasi
   
   Mulai fokus pada satu bidang:
   - Red Team: penetration testing dan ethical hacking.
   - Blue Team: SOC, monitoring, incident response.
   - AppSec: keamanan website dan aplikasi.
   - DFIR: digital forensics dan incident response.
   Platform: Hack The Box Academy, TryHackMe, PortSwigger.
   
   Estimasi: 1–3 bulan atau lebih
5. Tahap 5 — Portfolio & Certification
   
   Buat:
   - Dokumentasi hasil lab.
   - Laporan vulnerability assessment.
   - Proyek analisis keamanan.
   - Portfolio CTF dan sertifikat yang relevan.
   Berlangsung terus selama belajar.
